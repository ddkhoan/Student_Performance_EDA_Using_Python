# Student Performance Drivers: Demographic & Behavioral EDA

An exploratory data analysis identifying the socioeconomic, demographic, and behavioral factors most strongly correlated with academic success.

## Business Problem
Educational institutions struggle to identify at-risk students before they fail. By analyzing historical performance data, administrators can isolate key risk factors (such as attendance, study hours, or socioeconomic background) and proactively deploy tutoring and intervention resources.

## Dataset
* **Size:** 1,000 rows, 07 columns]

## Tools & Skills Demonstrated
* **Language:** Python
* **Libraries:** `pandas`, `matplotlib`, `seaborn`
* **Techniques:** Feature Engineering, Segment Analysis, Demographic Profiling, Correlation Matrices, Box-Plot Outlier Detection.

## Key Insights
* Previous Scores is the strongest predictor of Performance Index in this dataset (r ≈ 0.92), followed by Hours Studied (r ≈ 0.43). Sleep Hours and Sample Question Papers Practiced show almost no linear relationship with performance.
* Previous Scores is distributed close to symmetrically (skew ≈ -0.06) but flatter than a normal distribution (kurtosis ≈ -1.21), so scores are spread fairly evenly across the range.
* Extracurricular participation has only a marginal association with Performance Index (~2-point difference) and no meaningful association with Gender.
